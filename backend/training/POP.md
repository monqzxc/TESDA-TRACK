# Pop round: role-model goals ("I want to become like …")

Learners describe goals through characters and screen personalities: *"I want to become like Tony Stark"*,
*"gusto kong maging katulad ni Sanji"*. On these, production's v6-colab ranks a fitting qualification in the top
three for only about 25% of held-out queries (12–16% actually shown above the app's floor). This round continues
v6-colab with those goals.

## Data (`data/pop_culture/`, all drafts)

| File | What it holds |
| --- | --- |
| `directory.txt` | The source directory: 129 entries (126 characters after merging duplicates), skills and suggested TVET areas. |
| `area_map.json` | Each suggested area → exact catalog names. 36 areas have no catalog qualification (sports coaching, leadership, investigation…) and map to `[]`. **Needs a TESDA subject review.** |
| `unrelated.json` | 41 superpower and small-talk goals that must get no match ("I want to fly like Superman"). |
| `pop_items.json` | Generated by `python3 training/pop_culture.py`: 4,744 queries (en/tl/taglish, name and skill templates, typos). Characters with no catalog route (Wendy, Rock Lee, Samurai Jack, Elle Driver) are no-match goals. Splits: `train`, `eval_template` (held-out templates), `eval_unseen` (16 characters never trained on). |

No pop query equals a dev, test, sealed, probe or acceptance goal (checked with `training.v6._excluded`).

## Train in Colab

1. From `backend/`: `python3 training/pop_culture.py`, then build `training/runs/v6-dataset.json` in the backend
   image (`python -m training.v6 --dataset training/runs/v6-dataset.json`), then `python3 training/pop_notebook.py`.
2. Upload `colab/train_colab_pop.ipynb` to Colab, choose a T4 GPU, and **Run all** (try `SMOKE = True` first).
   It trains with `v6_train.py` on the pop queries ×2 plus 30% of the v6 goals and all 598 v6 unrelated goals,
   for about 460 steps (~30 min).
3. To publish it, set `HF_REPO` in cell 2 and add a write token as the Colab secret `HF_TOKEN`. Cell 12 creates the
   repo (private by default) with a model card.

The notebook's metrics use z ≥ 2.86 as "shown". That is where v6-colab's calibration (floor 2.0, ceiling 5.0,
keyword weight 0.3, minimum score 20) first shows a match that has no keyword evidence.

## Before adopting

Calibrate and gate it like any round (`V6.md`, *After training*), and compare it with v6-colab per language on
`test_v1`. skills-v1 passed on synthetic data but lost Filipino top-3 (0.85 → 0.60) on real goals.

## Results

**pop-v1** (25 November 2026, T4, 460 steps, `REPLAY_SHARE = 0.3`, `POP_REPEAT = 2`; private at
`monqzxc/tesda-e5-small-pop-v1`). Pop held-out top-3 rose from 0.245 to 0.906 (seen characters) and from 0.205 to
0.464 (unseen characters). Dev calibration gave 2.5/4.5/0.3/15, and the model passes `model_acceptance.json`, but
it is weaker than v6-colab on real goals, so it was not adopted:

| | v6-colab | pop-v1 |
| --- | ---: | ---: |
| dev top-1 / top-3 / rejection | 0.851 / 0.929 / 0.970 | 0.832 / 0.903 / 0.965 |
| dev Filipino top-1 | 0.737 | 0.702 |
| test_v1 top-1 / top-3 / rejection | 0.848 / 0.949 / 0.952 | 0.798 / 0.909 / 0.905 |

**pop-v2** replays the whole v6 dataset (`REPLAY_SHARE = 1.0`, `POP_REPEAT = 1`, about 1,190 steps), the notebook's
current default.

On a Mac with Docker Desktop's 8 GB, `training.evaluate` and `training.round` run out of memory (exit 137) with
fastembed's default batch of 256 passages. Run them with a smaller batch (16 works).
